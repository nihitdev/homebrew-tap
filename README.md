# Homebrew Tap

Homebrew tap for packages maintained by [nihitdev](https://github.com/nihitdev).

## Install

    brew tap nihitdev/tap
    brew install yoo

## Upgrade

    brew update
    brew upgrade yoo

## Uninstall

    brew uninstall yoo
    brew untap nihitdev/tap

## Packages

| Formula | Description |
| --- | --- |
| `yoo` | Local CLI for project, Git, and development environment information |

## Automatic updates

The `yoo` formula is checked automatically every hour against the latest
[nihitdev/yo-cli](https://github.com/nihitdev/yo-cli) release.

When a newer release is available, the workflow updates the version, release
URLs, and SHA-256 checksums from the published `SHA256SUMS` file.
